# ZYA – E-Commerce Clothing Platform

A full-stack e-commerce platform for a clothing store, built with React and Node.js.

## Tech Stack

* **Frontend:** React, Vite, Material UI
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL, Sequelize ORM
* **Authentication:** JWT
* **Deployment:** Docker

## Features

* Product browsing, search, filtering, and categories
* Product details with sizes and colors
* Shopping cart and favorites
* Checkout and order management
* User authentication
* Admin dashboard
* Product and image management
* Coupons and advertisements management
* Homepage content management
* Responsive design
* Arabic and English language support

## Project Structure

```text
ZYA/
├── frontend/   # Customer-facing application
├── admin/      # Admin dashboard
├── backend/    # REST API and database
└── .gitignore
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Admin

```bash
cd admin
npm install
npm run dev
```
